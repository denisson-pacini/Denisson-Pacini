# ScriptCriacaoBancoTabelasInsertConsultas

#Descrição
Script em fase inicial com o objetivo de implementar uma estrutura no banco de dados SQL Server utilizando comandos SQL, contendo scripts para criação de banco, tabelas, inserts e consultas.

## Tecnologia
 - SQL Server

## Como executar
 1 - Clone esse repositório 
   - git clone https://github.com/denisson-pacini/Denisson-Pacini
 2 - Ter instalado o SQL Server
 3 - Ter o SQL Server Management Studio (SSMS) ou outro cliente SQL
 4 - Clique em Execute ou aperte F5
